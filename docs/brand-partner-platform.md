# 赛电品牌伙伴平台

品牌伙伴入口 `/vip/`，总后台新增伙伴账户、合作等级、等级合作价、伙伴资金管理。默认战略合作、核心合作、优选合作；合作等级用于采购定价，只有当前启用的战略合作伙伴可查看所属会员健康资料。伙伴账户由超级管理员开通，独立密码及12小时会话；停用或重置密码吊销旧会话。

## 会员与推广

会员独立 `User.partnerId`，不替代原推广上级或佣金账户。专属链接使用 `partner=推广码`，进入 H5 注册页并明确告知伙伴名称和会员/健康/设备资料查看范围。同一注册会话保留首个经服务端验证有效的伙伴码；验证码登录及微信绑定仅在新建会员时绑定。无效码明确提示普通注册选择，已有会员正常登录且不改归属。App 无需深链接改造，后续使用同一账号。

伙伴接口的所有会员、设备、连接、测量、报告和心电附件查询按当前归属过滤，健康读取先完成审计再返回。每次请求核对主库当前合作等级；核心/优选合作只返回基本会员资料和设备连接信息，不返回健康档案、身体资料或健康数量，健康接口统一拒绝 403。设备旧标识兼容规则和未知健康值保留；不返回密码、会话、原始连接报文或内部对象存储地址。总后台人工归属调整即时生效，采购订单、价格与资金账本不随会员转移。

## 采购与资金

SKU × 合作等级定价；缺价、价格停用、商品下架或等级停用禁止采购。服务端重新报价并核对价格指纹，订单存成交等级、合作单价和运费快照。沿用现有中国大陆收货范围，不同发货来源分别下单。人民币整数分，采购不叠加积分、优惠券或推广佣金。

订单和支付恰有一个交易主体（会员或伙伴）。余额采购同事务完成订单、余额扣减、不可变账本、PARTNER_BALANCE 成功凭证、付款扣库存和ERP任务。沿用付款后扣库存与负库存补货规则；ERP任务事务提交后执行，同一订单号/支付凭证重试。浏览器保留未确认的原采购请求，重新登录另一伙伴不继承。

PARTNER_RECHARGE 复用商城支付配置、微信Native扫码和支付宝PAGE/WAP，只有已验签回调或服务端查单核实原商户、金额、币种和交易标识后入账一次。已付款但账户停用仍入账。渠道未配置明确不可用。充值返回 `/vip/recharges/:id`，前端返回页不能自行增加余额。

余额退款复用总后台商品级售后、部分/全额/运费审批与额度校验，本地事务退款回原伙伴，不调用外部退款、不写会员积分。充值退款及自助提现未开放。保证金通过独立 DEPOSIT 账本登记，不能用于采购，不限制下单；更正必须追加流水而非修改历史。

## API与部署

新基址 `/api/saydian-app/vip/v1`；鉴权为伙伴独立Bearer token。登录与公开推广来源验证以外均要求伙伴会话。接口目录、说明和资金操作字段见 [API目录](api-reference.md)。账户开通/改密/归属转移仅超级管理员，等级合作价允许商城运营，手动充值余额及保证金登记仅超级管理员，退款沿用商城售后权限。

`apps/vip-web` 与总后台、商城共用静态镜像，内外Nginx均需 `/vip/` 路由，组件缓存纳入新前端，发布检查覆盖 `/vip/` 和刷新登录页。两个迁移先提交枚举、再扩表和约束；新伙伴金额为零，不从旧财务projection推算。2026-10-13生产发布准备已完成SQL独立升级与回滚验收，按精确摘要登记兼容迁移；生产当前库备份隔离恢复成功后才能应用，结果见[生产发布记录](implementation-log/2026-10-13-brand-partner-production-release.md)。

## 验证

`pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm api:docs:check`、`pnpm tools:test`。真实数据库验收：本地已迁移的测试库使用 `RUN_LOCAL_DATABASE_TESTS=1 pnpm --filter @saydian/app-api exec vitest run src/partners/partner-database.test.ts`。拒绝非localhost数据库；测试保留独立随机命名合成账本以验证不可变性，建议使用可丢弃测试库。

本地预览及验证日志见实施记录；模拟资金/ERP回执与真实供应商联调分开记录，未配置渠道不展示为已接通。

## 2026-10-13 体验与人工入账更新

总后台“品牌伙伴资金”可由超级管理员手动充值余额及登记保证金；财务角色保留查询权限，不能执行上述资金写入。余额人工充值以MANUAL_RECHARGE流水记录，不生成在线支付收款凭证；保证金不转入可消费余额。每次登记须填原因，可附收款凭证编号，确认后追加操作人快照、前后金额和请求编号审计，重复请求只入账一次。

伙伴端菜单简化为首页、推广二维码、我的会员、商品采购、我的订单、余额充值、收支明细和保证金。弱网付款恢复始终保留原请求；金额变化需重新报价确认。新页面与权限验收见[本轮实施记录](implementation-log/2026-10-13-brand-partner-ux-and-manual-funds.md)。

点击余额支付后先核对收货人、联系电话、完整地址、商品数量、价格、运费、总额及付款后余额；最终确认才提交采购和扣款，返回修改不提交订单。确认展示与下单使用同一份信息，弱网恢复继续确认原请求。

ERP订单卖家备注附订单归属品牌伙伴ID和名称，读取服务端关联账户资料；可容纳时附伙伴编号和原卖家备注，买家留言单独保留。聚水潭remark限150字符，优先完整保留伙伴ID与名称，超长附加备注截断并标省略号，原始备注仍保存在本地订单中；原会员订单备注保持既有处理。实现与验收见[付款确认与ERP备注记录](implementation-log/2026-10-14-partner-purchase-confirmation.md)。

采购结算提供粘贴地址识别，使用商城已锁定的大陆地区字典在浏览器本地解析姓名、电话及省市区，支持常见省市简称、直辖市和省份补全。不调用外部服务；多个联系人拒绝自动填入，无法确定的字段留空并提示，旧/新地区名称保留原文提示核对。自动填写可撤销，不改变已经提交待核实的支付请求。

## 2026-10-14 合作体验更新

充值默认 10,000 元，已有未决充值保留原金额。总后台资金页默认分页列出伙伴，直接选择充值余额、充保证金、采购订单和资金明细。资金写入仍只允许超级管理员。

订单详情新增 ERP 处理明细，使用聚水潭 order.action.query 按真实订单内部 ID 同步操作、时间、操作人和备注；只读任务按分钟去重，失败保留最后成功记录并显示同步状态。

首页可查看和打印赛电电子授权证书，使用提供的红色透明 LOGO。授权随合作账户启用状态有效，二维码实时核验当前伙伴名称、合作等级及状态。公开核验不包含登录账号、联系方式、内部 UUID 或资金；打印前刷新授权状态。
