## 必测业务场景

1. 同一 Refresh Token 并发两次，恰好一个成功；退出后旧 Access Token 立即 401。
2. 验证码限频、五次错误、原子消费和重放失败。
3. 健康批量 200 条、部分失败、重复 Idempotency-Key、跨时区、未知值不变成 0。
4. ECG gzip 类型、大小、魔数、SHA-256、归属与重复索引。
5. 双账号关爱邀请、接受/拒绝、逐指标授权、到期、撤销后立即 403 和审计。
6. 阈值提醒只按用户规则生成；Push 载荷没有手机号、Token 或健康值。
7. 多安装实例未读/已读同步，Worker 重试、去重与死信。
8. 单订单包含多商品且只生成一个主库订单；价格/库存重新校验；旧订单只读并禁止支付/售后重放。
9. 微信/支付宝只使用服务端金额；微信回调时间窗和平台证书序列号正确；签名回调后再确认成功；重复回调、部分退款、伪造通知和支付结果回查。
10. StoreKit Sandbox 的商品、金额、币种、`appAccountToken`、跨设备恢复、退款通知和权益撤回。
11. 报告不足 3 天不收费；无效/零占位不进入证据；单次权益、30 天 4 次、过期、生成失败返还、退款撤权和历史重看。
12. 员工企业微信身份、推荐归因、赠券并发领取恰好一次、原始令牌不落库，旧提现只有只读历史。
13. AI 每条趋势只能引用输入中真实存在的指标，并由服务端附上对应健康记录 ID；伪造指标直接拒绝且不消耗权益。
14. 十类后台角色越权、原始健康查看审计、密钥不回显、接口文档双人审核、文件类型/大小和导出脱敏。
15. 迁移逐表数量、主外键、订单金额、退款、附件 SHA、健康有效/无效记录和永久 ID 映射。
16. 4GB 主机内存/队列/磁盘压力、备份恢复、发布失败回滚、只读开关和切换后日志回放。
