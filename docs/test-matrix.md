## 必测业务场景

1. 同一 Refresh Token 并发两次，恰好一个成功；退出后旧 Access Token 立即 401。
2. 验证码限频、五次错误、原子消费和重放失败。
3. 健康批量 200 条、部分失败、重复 Idempotency-Key、跨时区、未知值不变成 0。
4. ECG gzip 类型、大小、魔数、SHA-256、归属与重复索引。
5. 双账号关爱邀请、接受/拒绝、逐指标授权、到期、撤销后立即 403 和审计。
6. 阈值提醒只按用户规则生成；Push 载荷没有手机号、Token 或健康值。
7. 多安装实例未读/已读同步，Worker 重试、去重与死信。
8. 单订单包含多商品且只生成一个商城订单；旧订单只读并禁止支付/售后重放。
9. 微信/支付宝 APP 支付签名只使用服务端订单金额；回调后再确认成功。
10. 六类后台角色越权、原始健康查看审计、文件类型/大小和公开文档脱敏。
11. 备份恢复、发布失败回滚、只读开关和切换后日志回放。
