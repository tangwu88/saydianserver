# 商城微信小程序配置与验收

本轮补齐源码兼容与后台入口，未填写真实凭证、修改生产配置或部署。未读取线上配置，以下是上线前必须核对的配置项，不表示线上一定为空。

## 后台配置入口

后台 → 第三方服务 → 登录与消息 → **商城微信小程序**：填写小程序 AppID、AppSecret，凭证加密保存且不回显。完成配置后选择已配置；小程序支付开关默认关闭。域名清单用于交接，不会自动修改微信公众平台。

后台 → 第三方服务 → 支付收款 → **微信支付（H5 / 小程序）**：填写同一小程序 AppID、商户号、证书序列号、商户私钥、微信平台公钥及编号、API v3 密钥。商户资料与回调地址通过校验后，才允许在小程序卡片开启支付。AppSecret 不再从支付卡片读取。

更换或清除小程序凭证前须先暂停并保存。数据库现有 OpenID 仅支持一个小程序 AppID；已有微信身份时更换 AppID 会被拒绝，需要独立核验账号映射。本轮不迁移数据库或自动合并账号。

## 微信平台与服务器仍需配置

| 项目 | 要求 |
| --- | --- |
| 开发者工具 AppID | 与后台及源码一致；真实 AppID 不能用占位值替代 |
| request 合法域名 | `https://app.saydian.cn`，供商城 API、私有售后图片、公开协议请求 |
| uploadFile 合法域名 | `https://app.saydian.cn`，供售后证据上传 |
| downloadFile 合法域名 | `https://app.saydian.cn` 及商品图片/推广图实际 HTTPS CDN 域名；逐一核对商品数据 |
| 小程序类目、隐私保护指引 | 微信公众平台中按实际商城业务和读取/上传图片等能力申报并完成审核 |
| 微信支付 | 微信商户平台绑定同一小程序 AppID，确保服务端 HTTPS 支付/退款通知可达且签名校验有效 |
| 商城登录 | 发布简体中文用户协议和隐私政策；短信/邮箱服务须真实可用。首次微信登录引导绑定已验证会员，已有手机号或邮箱登录用户可在“我的”绑定微信 |
| 售后图片 | 服务端对象存储、上传能力、访问权限和保留策略须已配置；私有图片不会作为公开商品图处理 |
| 商城业务 | 商品、库存、配送、地址、订单及售后配置按现有后台管理；登录配置不代表支付或 ERP 已联调 |

后台域名列表填裸域名，例如 `app.saydian.cn`；微信公众平台中按其界面填写 HTTPS 域名。商品图片实际域名由业务数据决定，不能仅凭源码完整列出。不要用开发工具“忽略合法域名校验”代替真机验收。

## 构建和导入

在源码根目录安装依赖，在 `apps/shop` 中执行 `pnpm build:mp-weixin`。可在 PowerShell 设置 `$env:VITE_WECHAT_MINI_APP_ID='你的真实小程序AppID'` 后构建，或填写 `src/manifest.json` 的 `mp-weixin.appid`；不要把 AppSecret 放进前端。

交付 ZIP 中 `miniprogram` 是可直接导入微信开发者工具的编译源码目录；`uniapp-source` 是可修改重建的独立前端项目。导入时填写真实 AppID。源码未提供真实 AppID，因此默认构建 AppID 留空。

独立源码需要 Node 22+ 和 pnpm 11.19.0：进入 `uniapp-source`，执行 `pnpm install --frozen-lockfile`、`pnpm typecheck`、`pnpm build:mp-weixin`。依赖锁文件与允许构建脚本设置随包提供，避免临时解析到未经验证的版本。编译结果在 `dist/build/mp-weixin`。完整仓库回归测试包含主仓库 fixtures，保留在源码补丁中；独立源码包不包含这些依赖主仓库的测试。

## 本轮兼容范围

- 售后图片通过原生文件系统、带鉴权的二进制请求预览，切换账号或关闭页面清理临时文件。
- 商品、推广、优惠券海报使用小程序 Canvas；商品与推广支持原生分享。海报二维码仍指向商城网页，微信原生分享卡片指向小程序页面。
- 小程序使用独立能力查询、当前已发布协议同意记录和 JSAPI 支付；配置缺失或维护模式时保持关闭。
- 保留 H5 原有实现；新增微信绑定不替换会员账号、订单或既有会话。

## 必须真实验收

使用正确 AppID 和开启域名校验的开发工具/真机，依次验证商品图、首次会员绑定、重复登录、切换账号、分享、海报、售后上传与私有图片预览、下单、付款、支付回调、退款和维护模式。当前仅完成源码、自动测试及构建验证，未完成微信平台审核、实际登录支付、真机或生产部署验收。
