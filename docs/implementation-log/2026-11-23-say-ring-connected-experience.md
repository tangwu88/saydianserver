# Say Ring 分享、远程爱与固件管理

## 基线与范围

- 本轮使用独立分支 `codex/say-ring-connected-experience-20261123`，后台从 `dccccf3f38e853878120e6bff978b3fe9f1713ca` 开发。配套 App 内测构建为 1.0.15（1318）。
- 新增第一方 `/global/api/saydian-app/v2/ring` 和 `/global/say-ring`。分享、远程爱、固件分别通过 `SAY_RING_SHARING_ENABLED`、`SAY_RING_CARE_ENABLED`、`SAY_RING_FIRMWARE_ENABLED` 开关，模板默认关闭。
- 迁移只创建七张新表及其约束、索引。现有会员、健康记录、绑定及关爱授权继续使用既有表。涉及的范围为中国站服务。验证使用回环地址上专用的 PostgreSQL `ringlab` 数据库和合成账号。

## 接口行为

- 分享存储确认后的字段快照，链接 7 天到期。仅保存高熵随机令牌的摘要。H5 在浏览器片段接收令牌，社交预览为通用内容，响应禁止缓存。撤回后无法读回快照。访客回应按链接与浏览器访客标识去重。亲友可在已登录的 App 选择署名。回应进入发送者的现有收件箱。
- 远程爱邀请 48 小时有效，数据库事务锁定邀请与亲友关系，只有本人确认才生效。健康指标须由受邀者选择。问候、近况、可选散步记录、一周目标和 WAV 语音受关系权限约束。语音最多 10 秒，下载需鉴权。支持静音、屏蔽、删除和举报，后台统计邀请接受后 7 天双向问候比例和收到回应的有效分享。
- 后台固件页受应用运营权限和审计保护。可保存待发布包和证据说明。发布目标精确匹配平台、通道、型号、硬件、当前版本及目标版本。下发时附 Ed25519 签名及短期有效期，下载重新核对 SHA-256。签名密钥和真机通过名单需要由发布环境提供，允许暂停。
- 网关模板新增 H5 和 Android 验证文件路由。已运行过统一切换的环境需要将这些路由应用到实际网关。Android 关联文件只接受环境提供的正式证书指纹。本分支尚未登记入自动生产迁移清单，生产发布前需独立迁移评审。

## 验证结果

- 本机默认 Node 来源的 Rollup 二进制遇到 macOS 签名限制，改用校验过摘要的官方 Node 22.23.5。类型检查和所有应用构建成功。
- 首次 `pnpm test` 的旧应用包上传夹具因 macOS 临时目录的符号链接失败。改用规范化的 `/private/tmp` 新目录后通过，未修改上传代码。Apple 路由断言扩展为原回调加两条新关联路径。根测试中的数据库专项保留各自启动条件。
- `pnpm api:docs:check` 校验 633 条路由。部署脚本 56 项通过。隔离数据库迁移后，真实 NestJS HTTP 验证 4 项通过，覆盖分享权限、精确数值、撤回和去重，邀请并发接受、消息与语音权限、打卡，以及签名固件精确匹配和暂停。
- 独立 Chromium 320 px 测试确认实际页面渲染选中数值、通用社交标题、下载入口、访客回应落库和撤回重开失效。邀请码保留复制和下载回退。首次仅以英文断言检查中文浏览器得到假失败，改用浏览器语言模拟分别核对英文与简体中文后通过。

## 待验收

- 真机微信、WhatsApp、浏览器的正式证书关联、首次安装后接受以及系统通知送达。当前 H5 和 PostgreSQL 证据来自隔离环境。
- 原厂固件包、准确版本及恢复说明到齐后，在同型号的 iPhone 和华为上验证传输、中断恢复、原设置与历史保留。模拟签名和分发不会验证设备刷写。
- 本轮只提交开发分支。隔离验证没有修改线上数据库、服务开关或现有应用市场审核。
