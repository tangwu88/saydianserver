# 生理周期V2（2026-11-04）

用户要求实现独立周期记录、账号自动云同步、日历参考、来源与夜间质量、AI解读及普通通知；增强预测先内部验证。修改前2e883de与远端工作分支一致，工作区干净并fetch成功。读取AGENTS/handoff/最近云范围记录。保持旧法律文档对/正式AI配置/其他产品；不部署生产迁移、不用真实用户资料进行训练。

新增独立周期表和接口；每用户事务锁、修订冲突、幂等重放、删除标记及快照，来源新字段为可选保守扩展。源码、测试、构建、生产迁移和长期预测效果分别记录。所有失败/修正与待验收在下方追加。

## 修改内容和原因

- `apps/api/src/cycle/`：8个鉴权接口，复用现有第一方global网关；ownerHash另作会话切换竞态保护。用户行锁串行修订/删除，载荷绑定幂等键，冲突不静默覆盖；分页200项、推送40项，删除epoch使其他手机旧离线队列失效。
- Prisma仅新增CycleState/Record/Mutation/Artifact及HealthRecord.sourceMetadata；预测、夜间特征、解释分别存不可改写快照。擦除只清周期载荷及其重放/报告副本；账号注销worker补显式周期删除，保持现有健康数据/设备绑定语义。
- 日历按至少4个真实开始/3完整周期且确认历史完整生成，最多6个周期min/max；仅记录/历史不全不预测，过期不滚动。模型发布清单为空。
- 来源补充vendor/category/app/provenance/sleepWindows，原ID/数值/时间不变。严格白名单、不猜旧型号/固件/算法；真实睡眠窗口、时间来源、质量、覆盖及SDNN/RMSSD分组见`docs/say-ring-cycle-v2.md`。新增来源校验发现并纠正了普通r/n字符被正则错误拒绝的开发缺陷。
- AI专属说明类型/后台选择与默认关闭配置已接入，不发布说明、不改现行协议对。只有当前说明/同意/受允许供应商端点均匹配才外发匿名分类摘要；模型仅选动作，禁止自由生成日期/数字/诊断，故障固定回退。来源或同意变化后拒绝保存迟到结果。
- 共享契约、账号删除回归、接口用途注释/生成目录同步更新。新cycle代码格式化并在锁/删除代次/幂等处加中文说明，便于后续维护。
