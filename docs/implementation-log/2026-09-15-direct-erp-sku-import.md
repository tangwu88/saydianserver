# 2026-09-15 后台按 SKU 实时导入 ERP 商品

## 目标与范围

- 修复总后台“商城 → 商品 → 新增商品”中的“获取 ERP 资料”：资料来源改为服务端实时调用已配置的聚水潭接口，不再从本地主库已同步商品列表中检索。
- 输入单个 ERP SKU 后，同时读取商品资料与库存；两项均成功才以 ERP 草稿商品新增或刷新，随后由管理员维护商城展示字段。
- 不改聚水潭作为商品编码、SKU、售价和库存权威来源的边界，不增加手工伪造 ERP 商品的入口。

## 实现

- 新增 `POST /api/saydian-app/admin/v1/commerce-products/erp-import`，仅 `SUPER_ADMIN` 与 `COMMERCE_OPERATIONS` 可调用。
- 服务端使用集成中心中加密保存的 AppKey、AppSecret 与 Access Token，兼容现有 `sku.query` / `inventory.query` 网关和聚水潭 V2 `/open/sku/query` / `/open/inventory/query` 配置。
- 商品查询严格传入单个 `sku_ids`；V2 查询额外请求采购价、多图和库容字段。库存接口返回有效数量后才进入数据库事务。
- ERP 名称、编码、规格、条码、图片、售价、市场价、成本价、重量、启用状态和库存进入主库；品牌、简称、图片与标签只在商城展示字段为空时补齐，避免覆盖管理员已经维护的展示内容。
- 接口返回聚水潭公开文档中已知的完整商品与库存字段快照，后台表单提供折叠式只读查看，便于核对本次实时结果；密钥和签名不会返回浏览器。
- SKU 不存在、集成未配置、密钥不完整、接口无权限、库存缺失或供应商失败均返回明确中文错误；失败时不新增或刷新商品。

## 资料与边界

- 接口参数和字段按聚水潭开放平台 `/open/sku/query` 与 `/open/inventory/query` 文档复核；请求地址仍以后台集成配置为准。
- 本轮没有读取或输出生产密钥，也没有用截图中的 SKU 发起真实供应商调用；真实授权、调用频率和生产数据完整性须在发布后由有权限的管理员用已核对 SKU 验收。
- 无数据库结构变更和数据迁移。
