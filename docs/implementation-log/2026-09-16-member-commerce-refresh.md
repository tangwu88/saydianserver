# 2026-09-16 会员、推广、优惠券与商城界面更新

## 需求范围

- 微信公众号授权使用 `snsapi_userinfo` 获取头像与昵称；已绑定会员仅在头像缺失或仍为系统占位昵称时回填，避免覆盖会员主动修改的资料。
- 微信资料在待绑定流程中使用服务端签名且与一次性绑定票据绑定，客户端不能伪造头像或昵称；授权 access token 与公众号密钥不落库、不返回浏览器。
- 国内与国际商城的个人中心显示头像；后台会员列表显示头像、完整手机号、推广上级和积分余额。
- 推广码随验证码登录、首次微信授权及微信绑定流程进入服务端，未绑定上级的会员在有效推广员工下建立关系，后台列表可直接核对。
- 优惠券分享支持生成一次性领取链接和海报；未登录用户登录后回到原领取页，领取后进入待使用优惠券；结算页默认展开优惠权益并由服务端预览、下单抵扣。
- 放大商城底部菜单并补齐首页、分类、购物车、我的图标；商品详情操作栏固定在视口底部；首页“查看全部”右对齐并重做分类卡片。
- 后台超级管理员可按金额增减会员积分，限制负余额与单次上限，使用幂等请求编号，并写入会员积分流水和后台审计日志。

## 数据、安全与兼容性

- 本轮没有修改 Prisma schema，也不需要数据库迁移。
- 完整手机号只在管理员鉴权后的后台会员接口返回；健康原始数据权限不变。
- 积分调整仅允许 `SUPER_ADMIN`，单次绝对值不超过 100 万元，余额上限与非负约束在事务和用户级行锁内执行。
- 已存在的会员自定义昵称、头像和推广上级不会被新的微信授权或推广链接覆盖。
- 国内与国际版本共用的业务代码同步更新；国际分支仍需通过独立部署结构检查。
