# 2026-11-26 Say Ring HTML 标题与分享回应

开发基线为 `7039f9b`。排查时中国站运行 `0fb78cc`。公网「我的分享」列表未登录请求返回 401，单条回应路径返回 404。该版本的 H5 原始 HTML 标题为 Say Ring。

- 新分享链接通过查询参数携带分享令牌的摘要作为标题引用。服务端在返回 HTML 时写入分享者昵称、具体项目和已有留言，并对文本做 HTML 转义。标题引用校验开关、有效期、撤销与分享者状态。
- 标题请求只返回页面及标题，完整报告和回应由 URL 片段里的随机令牌授权。旧链接打开后核对令牌并补齐标题和地址。中文与英文标题共用项目名称，社交预览使用通用品牌标题。
- 同一中国站发布包含单条分享回应接口、原有分享历史与当前账号的权限校验。App 处理旧接口返回的 404／405 时读取自己的分享历史并匹配原分享 ID。
