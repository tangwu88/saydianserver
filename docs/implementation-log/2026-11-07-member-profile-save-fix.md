# 2026-11-07 会员编辑保存修复与中国站续发

## 复现与原因

用户在本地后台编辑合成会员 5，保存收到英文通用错误。浏览器真实请求确认 PATCH profile 返回 400。该会员手机号、邮箱均为空，服务端无条件要求至少保留一项，因而阻止普通资料编辑；异常过滤器将具体中文原因替换为英文。另确认 GET 返回空身高/体重，数字控件却显示最小值，存在误填风险。用户尝试将积分调整填为 0 时也会被阻止。

## 修复

- 仅在读取当前会员并检查版本、注销状态后判断联系方式：原本没有联系方式的会员允许编辑基本资料；已有联系方式的会员仍禁止全部清空。原超级管理员权限、验证状态及会话注销规则保留。
- 会员 profile 和 points-adjustments 两个后台资源保留可操作的中文校验提示；未知异常和任意 data 仍不回显，其它接口行为不变。
- 身高/体重改用可留空的小数输入，提交前验证范围并转为数字或 null，不自动补最小值。
- 积分留空或填写 0 均不调整、不创建积分流水，正常保存资料。非零金额仍必须填原因并确认。
- 增加 API、错误过滤器和实际前端 SFC 逻辑回归，更新接口文档。
