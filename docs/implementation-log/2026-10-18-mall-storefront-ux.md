# 商城 H5 体验与加载优化

## 请求、基线与边界

用户要求根据商城检查结果全面优化前端，视觉参照 https://www.saydian.cn/ ，允许从官网获取资料。`tools/Start-Change.ps1` 在干净 main 上 fetch / ff 成功，本地及 origin/main 均为 `0aeb6fadfd557f75f5884c0e71462e840d288433`；独立分支 `codex/mall-storefront-ux-20261018`。

仅修改商城前端、其静态资源服务配置及本地验证工具；不迁移数据、不修改商品库价格、库存、ERP 映射、真实资金或已发布协议。商品金额、库存、优惠、最终报价、订单幂等和身份校验继续由原服务端决定。本轮没有提交生产订单、真实支付或发货操作。

## 已实现

- 参考官网当前 CSS 色值：green `#245d47`、ink `#142722`、paper `#f7f8f4`、sage `#e9eee4`，统一首页、目录、搜索、商品、购物车、地址、结算、账户及 Tab 图标。沿用既有 Uni Icons 和品牌图片，不生成虚构产品图。
- 首页突出搜索、四个明确分类入口与精选商品，提供官网型号对比、戒指尺码和客服入口。客服信息取自官网：400-638-6738、8:00–18:00（北京时间）、公开企业微信客服链接。优先保留后台已配置的客服与政策，不硬编码未确认的发货时效或保修承诺。
- 公共目录缓存一分钟、合并并发读取、完整加载分页后再缓存；目录按公开商品名称归为手表/戒指/配件，隐藏空类，涵盖后端尚未归类的产品。搜索在完整目录中按名称/型号筛选、全局价格排序和整数分价格区间筛选；旧请求不覆盖新结果，刷新失败保留已显示目录并允许重试。
- 商品卡简化名称、隐藏供应链导入/内部色标，明确标注指模价格为“尺码工具价格”；详情将戒指与指模分组选择并明确工具不是戒指。默认选中有货的设备规格；设备全部缺货时不会偷偷改选有货的指模。保留原 SKU ID 和原价提交，下单最终重新核价。
- 当前 10 张公开商品主图生成 640px WebP 缩略图，原始 10,651,371 字节，缩略图共 479,230 字节（约减少 95.5%）；按精确原图片 URL 映射，新图片 URL 自动使用原图，不跨型号兜底。出处、原图摘要和大小记录于 `static/catalog/sources.json`。前两张优先加载，其余卡片按需加载，查看大图使用原始资源。维护命令 `node tools/refresh-shop-thumbnails.mjs` 需人工执行并审阅，不在 CI / 构建时访问生产站。
- 仅在商城 `/saidian-mall/assets/` 位置启用静态 JS/CSS 等响应压缩，保留既有一年静态缓存、页面 no-store，不更改 API 或健康附件缓存。
- 修复企业微信环境把商品等页面无条件转到推广中心的问题；保留原购物目标和推广参数。
- 购物车增加可售商品全选、失效商品确认清理、最近一次删除撤销；批量请求绑定开始时会话，切换账号后不继续修改新账号购物车。手机结算栏固定在 Tab 上方。
- 地址页复用既有 VIP 本地识别算法，加入粘贴识别和撤销。无需外部识别服务；多号码、地区不完整或无法精确匹配时不覆盖原地址。保存继续使用现有账号/国家/地区/号码校验。
- 结算显示免费运费和当前实际支付渠道、应付金额；停用渠道明确不可付款。桌面支付宝优先网页支付，手机浏览器使用 WAP，保留微信环境能力限制。报价变化、未知下单结果恢复、跨标签下单锁、维护及防重复提交逻辑保持。
- 账户增加待付款/待发货/待收货/售后快捷入口，保留最近订单及推广入口。停用邮箱验证码方式不可继续请求验证码。取消网页禁止缩放设置。

## 内容与生产限制

- 数据库中的缺图/缺详情、戒指与指模合并商品、中文商城正式协议等资料问题，前端仅提供明确区分及官网资料/服务入口；没有擅自重写或发布正式协议、修改 ERP 商品分类、拆分库存与价格。
- 缩略图体积减少不等于用户首屏耗时等比例减少；仍需部署后用真实移动网络测量 LCP/INP/CLS。本轮线上网络抽样及本地模拟均不代替生产发布与真机支付验收。
- 新配置的 Nginx 实际镜像语法/运行回执、生产压缩头及线上版本需要发布流水线核验；本轮本地构建不是已部署证明。
