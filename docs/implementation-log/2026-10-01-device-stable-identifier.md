# 2026-10-01 设备稳定脱敏标识

## 原因与实现

- 蓝牙名称、MAC 或型号缺失时，后台仍需要能区分不同设备。
- App 的 `deviceId/hardwareId` 是设备上报必填项，服务端已将它与会员绑定后做 SHA-256 单向哈希。
- 后台从该哈希生成 `DEV-XXXXXXXX-XXXXXXXX` 脱敏编号，并显示在列表、设备详情和连接记录。
- 每次成功连接会将全部 JSON 请求体按 `字段=值 | 字段=值` 写入连接历史的一个 `rawPayload` 字段。
- 后台连接记录可展开查看完整原始上报字符串。
- 会员列表操作区新增“查看设备”，仅返回所选会员的设备，并可继续查看单台设备连接记录。

## 数据边界

- 脱敏编号直接使用既有 `hardwareKey`；连接历史新增单个 `rawPayload` 文本字段。
- 列表与详情主字段仅显示脱敏编号；管理员主动展开“原始上报数据”时，可查看 App 实际发送的 `deviceId/hardwareId`。
- 脱敏编号在同一会员、同一设备上稳定，仅用于后台识别与排查。
- 原始字符串包含该接口的请求体，不包含 HTTP 请求头、登录令牌或服务器密钥；超过 65,535 字节时整体拒绝，不截断。
