# 2026-09-17 会员推广、佣金提现与首页布局调整

## 需求与实现

- 后台会员列表新增会员自己的推广码，会员搜索同时匹配自己的推广码及推广上级的推广码。
- 推广上级改为组合展示头像、完整手机号、昵称和推广码；这些完整联系方式只由后台管理员鉴权接口返回。
- 会员有可用佣金且不存在欠款或在途申请时即可提交提现，不再依赖预配置的最低金额、每日额度或预核验收款身份。
- 提现申请由会员填写微信、支付宝或银行卡收款资料；服务端在同一事务中从可用佣金转入提现冻结并记录账本。
- 后台审核通过前明确要求财务完成线下付款；审核通过后在同一事务中把冻结佣金转入累计已付并将申请标记为已提现，拒绝则释放冻结并优先抵扣退款欠款。
- 本系统仍不自动调用任何第三方转账；历史已审核或迁入在途记录保留原回执核验入口。
- 商城首页分类改为横向单行滚动；精选商品标题占满剩余空间，“查看全部”使用固定的右侧对齐规则。
- 国内版与国际版同步修改；本轮没有修改 Prisma schema，不需要数据库迁移。

## 安全与兼容

- 普通会员提现记录只返回脱敏收款账号；完整收款资料仅由财务或超级管理员鉴权接口读取。
- 提现仍保留用户钱包行锁、幂等键、在途唯一限制、余额非负、退款欠款、乐观版本、账本与后台审计。
- 已有 APPROVED、供应商处理中及迁入记录继续使用原手工回执/原转账核验流程，不会被重新付款。
- 推广码来自会员对应的推广账户；尚未创建推广账户的会员显示“未生成”，不会因后台只读列表产生隐式写入。
