# 国际后台健康数据中文展示与 AI 报告入口

## 基线与范围

- 用户要求超级管理员查看原始健康记录时不再填写原因。本轮只改变国际超级管理员的输入步骤，保留原有读取权限和强制访问审计；健康审核员仍填写 5 至 300 字原因，其他角色仍禁止访问。
- 读取 AGENTS、handoff 和上一轮分类实施日志；修改前 status 干净，fetch 后国际功能分支本地/远端均为 `0d072df2a3bdf37c10c18e3f0e846147863468d8`。不更改国内工作区、App 或数据库结构；main-only 发布工具不用于此国际功能分支。
- 前端根据当前角色略过原因弹窗，不传伪造原因；服务端仅使用 AdminAuthGuard 从有效会话及数据库读取的角色决定豁免，不接受 query 中的角色/豁免标志。
- 无人工原因时记录明确系统说明及 `reasonSource=SUPER_ADMIN_EXEMPTION`；有原因记录 PROVIDED。操作者、会员 UUID、时间、请求编号、记录数量继续审计，审计落库失败不返回数据。原国内原因规则和审计结构不变。

## 验证记录

- 用户在同一轮补充：原始记录中文易懂、摘要简洁，同时提供 AI 分析生成报告按钮。增加独立展示组件和报告面板；复用现有模型/证据汇总/次数权益/Outbox，不新增数据库表，不修改 App。
- 原始记录突出中文指标、实际值和原单位、时区和来源；UUID/原JSON保留折叠，未知不补零，不标正常异常，不把ECG评分解释为诊断。摘要固定展示中文指标/次数/最早/最近UTC时间。
- 新管理接口限SUPER_ADMIN/HEALTH_AUDITOR；生成前检查数据、会员状态、本人当前有效同意、报告次数、AI配置/凭据和暂停开关。明确确认消耗1次报告权益，相同请求/证据复用，不下支付单。数据库会员锁保护各创建入口，报告/扣次/Outbox/生成审计同事务。
