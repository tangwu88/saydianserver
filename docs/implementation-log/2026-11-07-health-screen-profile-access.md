# 会员大屏资料编辑、体态插画与本人访问

2026-11-07。基线为 `a6257b1fe641546be470b11da727a2f73f05afb3`。本轮按用户选择交付本地预览。

## 会员入口与编辑

- 在管理、伙伴及本人入口，姓名、性别、出生日期和体重齐全后才放行数据、记录、参考值和 AI 任务。历史昵称可以带入补全表单，由有权限的录入者确认。健康档案姓名单独保存。生日、性别、身高体重复用会员表字段。
- 页眉姓名、页眉编号以及校准对话框中的姓名和编号都可打开同一资料窗口。会员本人、超级管理员可保存，审核员和战略伙伴按原角色和归属查看。编号只读。身高选填。资料更新使用数据库行锁和读取时的版本，旧表单遇到并发写入时返回 409。审计保存变更字段名。
- 大屏重新聚合后立即使用新的姓名、年龄、性别、体重。后台修改与校准草稿各自保存。隐藏姓名开关继续适用。
- 中国站会员可从无工作人员会话的链接进入，通过商城验证码或微信扫码确认建立仅限大屏的会话。本人接口从有效会话确定唯一会员。手机扫码凭证、桌面领取凭证及限大屏会话均只在服务端保存哈希。二维码有效期3分钟。手机确认及一次领取、过期、撤销和原会话联动均有验证。

## 展示及评分

- 四个展示年龄段为0–11、12–17、18–59、60岁及以上。每组各有男女两张素材，服务端按会员时区计算周岁。资料缺失时保留补全表单。成人有身高和体重时对通用插画宽度作小幅调整。儿童使用穿着运动服的插画。素材来源和生成提示见 [人体素材说明](../../packages/health-screen-ui/src/assets/profiles/README.md)。
- 评分草稿可选12个设备指标及11个独立参考指标。参考血压按收缩/舒张分开，血糖按空腹/餐后2小时/随机分开，血尿酸按测量情境区分，空腹血脂按四项分开。每项选定一个来源和单位，只有审核发布的规则可以据此计算。切换参考单位或来源时清空原区间和依据。未发布规则、缺失和待核实记录均保持可解释的状态。
- 主要变更在 `packages/health-domain`、`packages/contracts`、`packages/health-screen-ui`、API 的 health-screen 及 worker、后台与伙伴路由、商城扫码确认页。新增兼容迁移 `20261107190000_health_screen_member_access` 及散列登记，接口清单随控制器生成。
