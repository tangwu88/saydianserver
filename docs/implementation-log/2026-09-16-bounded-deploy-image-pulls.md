# 2026-09-16 生产镜像拉取超时保护

## 目标与范围

- 修复自动发布在生产机访问 GHCR 卡住时永久占用 `.ci-release.lock` 的问题。
- 仅调整 CI 发布脚本及对应静态测试，不改应用业务、数据库或运行中容器。

## 证据与实现

- GitHub Actions 运行 `34970588079` 的生产发布持续 3 小时 15 分钟；日志显示 API 镜像已拉取完成，随后停留在 `worker Pulling`，任务取消后远端发布锁仍被保留。
- 每个 API、Worker、Admin 镜像拉取现在由 GNU `timeout` 限制为 90 分钟；超时先发送 `TERM`，30 秒后仍未退出才发送强制终止信号。
- 保留原有逐个镜像、最多三次重试和回滚逻辑。正常拉取成功时行为不变；超时或失败时会进入既有重试，最终失败则触发既有回滚。

## 验证

- `pnpm tools:test` 通过；覆盖发布脚本 shell 语法、超时命令形态和既有 H5 工具链检查。
- 仓库完整发布门禁将在提交前执行并记录。
- 此修改只能防止后续发布再次永久占锁；当前由旧版本脚本遗留的远端进程仍需先由服务器管理员核对并终止。
