原分类手机侧栏挤占双列商品区域，卡片价格/状态拥挤；分类、搜索切换时旧请求可能覆盖新结果。改为手机横向分类、电脑侧栏，统一商品卡片留白、触控尺寸，保留原品牌素材。请求按当前分类/搜索快照接收；错误有明确重试，翻页不会串入旧条件。

- 线上原状态：`08-live-global-category.png`。
- 修复后本地合成目录：`10-after-category-mobile.png`、`22-category-small-phone.png`、`23-category-tablet.png`、`24-category-desktop.png`；按 320/390/768/1280 像素视口检查，无横向溢出。
- 搜索失败/恢复：`11-search-retry-error.png`、`12-search-recovered.png`。
- 商品缺图、缺描述仍明确标为未知，不盗用不对应商品的图片，也不编造性能宣传。

### 2. 商品、登录与身份

国际消费者商品页显示购物车、收藏、数量和购买按钮；缺货、未知库存或无效 SKU 不能新下单。未登录点击购买先登录，登录完成回到原商品。手机号地址默认 +86，独立会员数字编号、邮箱/手机号验证与会话隔离保持。

真实本地 global Nest API + 独立演示数据库浏览器验收使用本轮合成、已验证邮箱会员；登录页引用仅测试进程的内存 QA 条款，不替用户接受真实新协议。不调用真实微信换码、不制造 WeixinJSBridge。iPhone/MicroMessenger UA 只验证页面分支，真实微信授权、手机号验证和支付还需真机及外部环境验收。

### 3. 购物车

开放四项底部导航“首页、分类、购物车、我的”和电脑购物车入口。重复加入同一 SKU 累加数量；已选件数按数量求和。补缺图提示、库存不足保护、44 像素数量按钮、失败重试以及小屏金额布局。

本地 global 浏览器：同一 19.99 元商品点击加购两次，购物车为 2 件、39.98 元。截图 `28-global-cart-open.png`。原共享领域演示亦检查 320 像素小屏（`21-cart-small-phone.png`）。

### 4. 地址、报价与下单

国际地址提交 `countryCode=CN` 和 E.164 `+86` 手机号；回填不重复加区号，不把已有非 CN 地址悄悄改成 CN。国内地址载荷不变。非 CN 收货被服务端明确拒绝；显式关闭市场的设置继续生效。

下单使用服务端报价，不使用购物车缓存金额：增加可选 `expectedQuote=q1:sha256`；商品价格、券、积分、运费及分摊变化时，事务在资产写入前返回 409 `quote_changed`。H5 刷新报价后须再次确认新金额（`25-quote-changed-confirmation.png`，39.98→49.98 元，没有按旧展示静默建单）。旧客户端未发送该字段的兼容性保留。

幂等键及原请求持久化；进程中事务锁与事务内已存在订单重查防止重复预占。处理中请求返回 503，H5 保留相同请求和键，不把尚未确定结果误当作失败清空。跨页/跨标签/账号切换均有归属检查。

![改价后的第二次确认](F:/xcodeplace/saydian-server-global/artifacts/h5-wechat-audit-20260911/25-quote-changed-confirmation.png)

### 5. 支付与中断恢复

国际商城支持五个现有 H5 渠道：微信 JSAPI/H5/Native、支付宝 WAP/Page，按微信内/普通手机/电脑筛选。前端显示与创建支付接口使用相同有效配置门槛；公众号绑定、商户参数、RSA 私钥和平台验签公钥、APIv3、回调 HTTPS 等不齐全不能创建支付单或出站。只允许商城订单 CNY 支付，不顺带开放其他业务或小程序。

本地 global 浏览器成功创建唯一订单 `d07406e6-69cb-47c9-960f-7eb7ba5ee88e`、3998 分；刷新仍为同一待付款订单。截图 `29-global-pending-order.png`。未配置支付提示与不可点击继续支付见 `30-global-payment-unconfigured.png`；没有产生真实收款、ERP 推单或出库。

独立审查另发现“最后一件下单响应超时后，库存为零挡住恢复按钮”及“市场关闭后既有不确定订单无法查回”组合问题；针对原归属会话的冻结请求补恢复入口，仍禁止新建或跨账号复用，维护停写边界不放松。

![真实支付未配置保持待付款](F:/xcodeplace/saydian-server-global/artifacts/h5-wechat-audit-20260911/30-global-payment-unconfigured.png)

新增个人中心订单/待付款/待收货/售后、地址/收藏/券/积分入口，没有员工身份混用。订单状态五项筛选在手机完整显示；列表错误可重试、异步旧请求不覆盖新筛选；详情有全部订单入口。

## 数据与运行隔离

- 8081、5174 为本轮共享领域演示服务；5189 为只读合成目录视觉夹具，不应当作生产购买演示。
- global 追加验收：单独 Nest 8091、H5 5176；运行时合成账号及商品，没有复制生产数据或集成密钥；测试环境出站限制为 loopback。
- 首轮 global 自动阶段 142 断言 / 43 HTTP，通过后开启只读第三方配置的 UI 预览。浏览器操作后以 `finish` 正常关闭；整轮 167 断言，清理核验通过。随机 marker `3a2288b1-e585-4593-ae76-f905d2b0d36b` 的商品、账号、地址、订单及支付依赖已清理，保留原 6 件演示商品，不操作生产数据。
- 新完整支付配置门槛落盘后另行无预览重跑终验，使用内存随机 RSA 测试材料，不写密钥到数据库或文件；真实支付仅最后传输适配器替换为内存测试回执。这不等于真实微信/支付宝回执。
- global 冻结版最终结果：166 断言 / 43 HTTP，run `995865c3-bd3a-4669-9283-88a3619ff1a2`，`cleanup=true`。真实 `identity/create` 完整配置检查执行，缺 APIv3 字段返回 503、支付单 0、出站调用 0；恢复内存测试配置后相同幂等键仅调用一次测试适配器。两轮 marker 残留会员/商品/订单/支付单均 0，原 6 件商品保留，集成密钥仍 0。
- 更早共享领域全链路终验 271 断言 / 68 HTTP（run `33bcb37f-7af0-493d-905d-4721a368dc56`），包括部分退款、积分尾差、取消返还、并发库存、重复回调。详见同目录 `2026-09-11-h5-isolated-acceptance.md`；不将该共享领域结果冒充真实 global 微信支付结果。
