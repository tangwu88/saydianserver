## 核对中发现并修复

- Vue 响应式对象不能直接 `structuredClone`：改用 JSON 配置快照，并增加响应式对象测试。
- PEM 不能用单行密码输入：改成保留换行的文本域，且不回显原凭证；校验只检查基本格式与类型，不冒充证书有效性验证。
- 布尔配置需要区分继承、真、假，并兼容服务端字符串表示；未经编辑的原始值不改写。
- 不自动填入供应商默认值，防止打开表单就覆盖服务器配置。
- 不能在用户选择“暂停”之前强制补齐原有服务器配置：调整步骤，并允许未改字段在停用时保持原样。
- 选择控件的默认英文提示改为中文。
