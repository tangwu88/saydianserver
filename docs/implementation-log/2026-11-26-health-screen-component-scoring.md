# 2026-11-26 健康大屏分项评分

开发基线为 `2d332fe`。旧版发布校验要求所有指标填写分档，只有一个加权指标时，大屏会把它的分数显示为健康总分。中国站第 2 版需要单独发布整夜睡眠时长评分，同时保留其他七项体征的数值、来源和趋势。

- 共享契约和服务端支持按规则版本选择分项模式，以及按指标选择趋势用途。分项版至少需要一个具备分档和依据的评分项，返回的总分为空。趋势项保留记录数、覆盖天数、依据值和单位。既有规则继续使用原来的加权算法。
- 后台编辑器支持这两项选择，并可对已保存的草稿运行合成样本预览。样本预览使用正式聚合与校验逻辑，在超级管理员权限下执行，记录规则审计。会员、伙伴和管理端共享的大屏展示分项名称、分数和覆盖情况。睡眠依据值换算为小时。
- 第 2 版拟用于至少 20 岁、周期内有至少 3 个有效整夜记录的会员。分档取自美国心脏协会《Life’s Essential 8》表 1 的成人睡眠时长项，3 晚为本产品的覆盖门槛。心率、收缩压、舒张压、血氧、日步数、空腹血糖和空腹血尿酸用于观察趋势。[成人睡眠时长依据](https://www.ahajournals.org/doi/10.1161/CIR.0000000000001078)

| 仓库检查 | `pnpm typecheck`、`pnpm test`、`pnpm build`、`pnpm api:docs:check`、`pnpm tools:test`、部署脚本及差异检查通过。接口目录包含 634 个已说明的路由。 |

首次本机回归遇到 macOS 临时目录的符号链接路径差异，改用规范路径后通过。备份恢复演练使用校验过源码的同版 PostgreSQL 工具。上线后的核验包括两个中国站健康检查地址、后台第 2 版合成预览和正式发布状态。样本用于核对计算及展示，未读取真实会员记录或调用千问。
