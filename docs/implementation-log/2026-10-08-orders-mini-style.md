- 已阅读工作约定、docs/handoff.md 和最近支付宝编码、库存、微信小程序配置实施记录。原用户工作树存在其他未跟踪资料，保持原样；在干净 main 工作树 E:/saydian-inventory-sync-20261007 执行 Start-Change，fetch 成功，本地及 origin/main 均为 f037228d74885c3f0d21d5560ab616fadaee9246，线上 readiness 同版本。
- 微信开发工具当前账号的只读待付款查询返回 10 笔 PENDING_PAYMENT；切换到待付款能显示订单，但首条为九月订单。CommerceService 合并当前 Date 与历史 ISO 字符串后按 String.localeCompare 排序，星期名参与排序，较新的订单被排到后面。没有证据表明取消微信收银台会删除业务订单。
- 小程序语义标签被默认编译为 view，原 b/h2 等选择器失配，行内金额换行；组件 WXSS 类型选择器被限制，公共商品卡片样式因默认隔离而缺失。个人中心仍选择旧版页面，H5 已使用新版。

## 变更

- CommerceService 按时间戳倒序合并订单，保持状态、会员过滤与历史订单去重规则；新增新订单 Date、历史 ISO 及九月旧订单的回归验证，覆盖全部与待付款列表。
- apps/shop/mini-style.ts 与 Vite 小程序专用编译插件：依据 Vue AST 加入原生节点类，标题/加粗映射为 view/text 并保留语义样式，组件选择器改为类选择器，禁用态与原动态类合并，组件使用 shared 样式隔离以继承商城公共布局。H5 编译不启用此适配，源模板不改写。
- 小程序个人中心使用 H5 的 GlobalAccount，增加小程序专属会员微信支付绑定操作；保留小程序存储命名空间、账号及原登录/支付协议，刷新同一会员资料与最近订单。登录页沿用原小程序授权和绑定流程，样式与 H5 的输入框、间距和主题对齐。
- 结算页已有订单时增加查看待付款订单入口；支付取消或失败不调用取消订单接口，原恢复订单与幂等键保留。
- 测试验证所有页面/组件经过转换后的 Vue 语法、动态禁用类、金额行内显示及样式选择器；更新 H5 manifest 测试的插件查找方式。独立小程序源码需同时交付 mini-style.ts，原导入路径更新编译文件，备份保存在忽略的 artifacts 内。
