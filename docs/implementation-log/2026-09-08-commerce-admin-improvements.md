## 后续微调：子菜单切页保持展开

- 用户要求点击子菜单后不自动收缩。移除 `AppShell.vue` 中监听 `route.fullPath` 并关闭全部分组的逻辑，保留首次进入时的 `onMounted(closeAllGroups)`。
- 预期结果：初始子菜单仍关闭，点击商城分组展开后，再点击商品、轮播、订单等子菜单时保持展开。
- 验收发现 Element Plus 的 `router` 内置高亮会保留上一个子项的激活样式。移除内置 `router` 属性，改为点击时调用 `router.push()`，仅由 `route.path` 控制当前子项高亮。
- 变更过程中仍可能残留 Element Plus 旧的 `is-active` 样式。为非 `manual-active` 的旧激活项明确恢复侧边栏普通配色，保证同一时间只高亮当前路由子项。
