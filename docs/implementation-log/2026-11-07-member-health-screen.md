# 会员 AI 健康体征分析大屏与参考值对照

## 原因与本轮边界

按用户确认方案为中国站总后台、战略伙伴网页实现按会员的健康大屏。后续追加“校准”、循环/心跳示意动画、新记录部位提示；用户明确选择“仅录入参考值并对照分析”，不修正设备读数。交付本地可操作预览，未执行 Git 提交、推送、生产部署、开放生产入口、发布评分规则或真实会员千问调用。

修改前已阅读 AGENTS.md、handoff 和最新记录；通过 Start-Change 检查并将干净 main 快进到 `3b7cfd41a9657a2dd5587a612502bf4ada104208`。本轮在该工作区保留源码变更。生产功能开关默认关闭；本地预览仅启用隔离合成数据。

## 文件与实现

- `packages/health-domain`：完整7/30/90会员时区聚合，跨夜、DST、重复和日累计语义；来源/质量/单位分离；确定性评分、当前权限和授权、共享扣次/退次锁。参考测量校验及独立系列。
- `packages/contracts/src/health-screen.ts`：共享展示、评分、记录、参考值及任务契约；权限契约新增健康大屏/评分规则资源；完整 API 字段与路由文档生成。
- `apps/api/src/health-screen` 及 admin/partner 控制器：聚合、分页、更新检查、手动参考值追加/撤销、规则草稿/预览/发布、任务幂等与访问审计；每次复核当前角色/等级/归属。敏感结果 no-store，维护停写仍有效。
- `apps/api/prisma`：两次兼容迁移，新分析/规则/参考值3表，ReportCreditLedger可空关联；SHA已登记 compatible-migrations.json。原测量不被修改；参考值独立储存、不可覆盖、保留撤销历史。
- `apps/worker/src/member-health-analysis*`：独立千问任务及结构化证据；去标识化统计、参考值与设备数据分离、模型不计算评分。任务前/发送前/落库前复核权限与授权，重试及失败幂等退次；注销清理新增表。
- `packages/health-screen-ui`：共用响应式Vue大屏、真实生成2.5D透明人体资产、趋势图、分页记录、校准对话框、示意动画、更新提示；原始数据不进浏览器持久存储。手动参考值仅供对照，不计入评分基础数量。初次加载/切周期不报“新数据”。
- admin/vip 路由及会员入口；后台规则编辑页面。独立窗口沿用现有浏览器会话，立即断开 opener，限定同站内部会员路径，不把token写入URL或localStorage。
- Docker API/worker/admin构建与组件缓存包括新共享包；CI增加隔离PostgreSQL授权/额度测试。`tools/health-screen-local.mjs` 仅允许命名的本地合成会员，用于API/前端预览及模拟新测量。

新增验证：界面保存合成血糖和血压参考值，趋势与设备来源分列；手机撤销血压后保留原值/时间/原因并排除当前聚合；伙伴端可见所属会员参考历史。通过本地脚本追加合成心率和血氧记录，10秒检查内两个对应热点出现提示，图表计数更新。暂停按钮使动画 paused；浏览器模拟 reduced-motion 后动画全部 none，再恢复模拟设置。未连接物理设备，模拟上报不作为真机证据。

尺寸：1536×1024与参考图同尺寸对照；1920×1080、2560×1440、3840×2160、390×844逐项检查；手机内容宽375（浏览器滚动条占15），工具栏完整可见，无横向溢出；4K zoom1.5填满画布。截图与比较见根 `design-qa.md`。

## 失败与修复

- 新窗口noopener导致sessionStorage不能复制：限定内部路由，先打开同源空页继承现有会话，再立即断开opener，随后导航；实际两端点击验证通过。
- 本地Vite共享CJS具名导出问题：补充optimizeDeps，原空白页面恢复；不是生产接口故障。
- 参考值事务锁 `$queryRaw` 无法反序列化PostgreSQL void：改为 `$executeRaw`；浏览器保存重试与并发数据库测试通过。
- 窄屏新增校准/动画按钮挤出工具栏：允许换行并设44px触控目标；重新测量所有控件均在视口内。
- 4K此前内容最大宽度导致空白较多：使用适当内容缩放及全宽布局；重新截图核验。
- 既有工具测试受macOS临时目录符号链接和pwsh缺PATH影响：使用规范TMPDIR和本机已装PowerShell，不更改原测试语义。
- 自编译pg_dump经pnpm shell丢失DYLD_LIBRARY_PATH：直接node运行同一升级脚本并传本地libpq路径；真实dump/restore通过。
