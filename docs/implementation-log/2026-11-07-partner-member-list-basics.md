## 修改

- 新增 MemberListCard：头像/昵称/会员编号、手机号与邮箱、基础资料、设备/健康记录数和注册时间分区。联系方式两项同时显示，两个操作按钮统一放入操作组，保留原档案抽屉和健康大屏入口。
- 战略合作显示性别、年龄、身高、体重；其他等级只显示已有基础权限字段，隐藏年龄、身体资料和健康数据入口。未知资料显示“未填写”，真实设备/记录数 0 保留；年龄按中国日期和已过生日计算，不展示完整生日。
- 普通屏单列，宽屏双列；手机操作按钮至少 44px，高度一致，长昵称/邮箱换行。手机搜索、搜索按钮、图标刷新在同一行，刷新保留可访问名称。
- 服务端在现有 members 分页查询中仅为当前启用战略合作等级选择 birthday、heightCm、weightKg 和健康记录计数，不逐会员调用详情接口。所有读取继续限定当前 partnerId 和未删除会员；显式 DTO 白名单避免附带其他资料字段。
- 资料列表查询在同一 RepeatableRead 事务中检查当前等级、分页读取、记录 USER_PROFILE_LIST 审计，再返回。审计保存当前伙伴、请求编号、页码和条数，不记录身体资料值或联系方式。名单响应 private/no-store；不新增迁移、业务写入或伙伴权限。
- 更新对应接口说明与生成目录。原 App 与商城资料仍共用 User 字段；本次不改会员编辑、采购、资金或健康分析实现。
