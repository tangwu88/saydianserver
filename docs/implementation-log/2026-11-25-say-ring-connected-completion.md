# Say Ring 分享、远程爱与固件内测续验

2026-11-25。候选从 `75f00a0` 合并了已拉取的 `origin/main` `62bf80e`。对应 App 为 1.0.15（1323）。

## 接口和网关

- `GET /global/api/saydian-app/v2/ring/shares` 支持 `history=true` 和本人分享 ID 游标。旧调用默认只看有效链接。过期的私有回应供本人读取。匿名链接仍按有效期和撤回规则执行。
- 睡眠允许分享真实周月汇总。每周回顾新增同期运动和睡眠的显示字段。H5 和 App 共用字段含义，用户主动勾选后才写入快照。
- 散步约定只用服务端已有的本人、当天、有效穿戴步数校验活动打卡。另一方只看到进度与目标。后台 7 天双向问候比例以已观察满 7 天的邀请为分母。
- H5 的 Android 打开按钮明确指定 Say Ring 包名，有 HTTPS 回退。Safari 跨域打开可使用固定的 `links.saydian.cn`。在主站 `SAY_RING_APP_LINK_HOST_ENABLED` 打开前，公开 HTTPS 证书、Apple AASA、同源邀请预览均须验证。安装后仍可点原消息或复制邀请码。分发链接中的令牌仍放在浏览器片段中。

## 迁移独立演练

在仅监听本机的独立 PostgreSQL 数据库，先用 `origin/main` 的 Prisma schema 和迁移部署，写入合成会员及活动记录，再运行候选的 `prisma migrate deploy`。原账号和对应健康记录原值读回，新分享表为空。迁移新增七张表、索引和这些表上的外键。原业务表的数据无需改写。按实测 SQL 摘要登记该迁移。

统一部署的网关更新会补入 Say Ring H5、Android 关联文件及 AI 消息接口的专用路由。模板由 `deploy/global/nginx.locations.conf` 提供，例行发布沿用原有备份、配置检查和回退流程。AI 消息接口的网关等待时间为 70 秒，模型服务为 60 秒，App 为 75 秒。该调整给服务端留出返回模型错误的时间，保留普通接口的 60 秒设置。新增跳转域名使用单独的 `nginx.ring-link-host.conf`。保留发布前的业务和分项开关。正式签名证书指纹使用真实渠道的签名文件核对，部署后从两个 readiness 端点及公开关联文件读回。

## 检查与未验收

- `pnpm typecheck`、`pnpm build`、接口目录检查（633 条）、`node --test deploy/scripts/*.test.mjs deploy/global/h5-deployment.test.mjs`（48 项）和工作区测试（2,523 项通过，116 项按环境条件跳过）均通过。独立数据库下另有 7 项功能与关联测试通过，覆盖过期回应、分页归属、活动记录校验、邀请并发、语音隔离和固件暂停。
- 执行构建后的 H5 脚本，核对 Android 意图及回退、iOS 跨域开关、失效邀请、固定分享快照和重复回应拦截。使用华为系统解析器确认邀请片段在 Android 意图中保留。微信及 WhatsApp 内打开仍需实测。
- 初次编译发现工作区仍有主线变更前的 contracts 产物。重新编译 contracts 后 API 与全工作区通过。macOS 采用已核对官方摘要的 Node 22 临时运行时。
- 本机公开探针确认部署前的分享和邀请路由返回 404，Android 关联文件未发布，`links.saydian.cn` 的证书与域名不匹配。生产接口、真实社交转发、推送和固件实物回读仍需独立验证。
- 已登录的华为测试账号以合成数据请求线上模型，两次 7 天和一次 30 天请求均返回 HTTP 504。已复现旧网关和模型服务使用相同超时的配置；网关调整上线后需要用返回的错误及服务端诊断确认超时原因，取得新的真实回复再完成联测。
