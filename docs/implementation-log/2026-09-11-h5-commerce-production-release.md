# 国际 H5 商城购物闭环生产发布

## 目标、基线与发布边界

- 用户要求本轮修改完成后更新服务器。发布对象仅为独立国际服务：`https://app.saydian.cn/global/`、国际 H5 `/global/saidian-mall/` 及 `/admin/` 使用的国际后台；不修改国内 App、旧域名、国内数据库或旧商城。
- 发布前分支为 `codex/global-api-foundation`，本地、远端与公网 `/global/health` 均为 `0f9c7e0457e9ab554d92b72a913cd706ec63e09f`。国内 `/health/ready` 保持 `795e66bd69c64295a00c2b3e42c52a290c8f56eb`，两套服务未混用。
- 本轮显式发布现有 H5 顾客购物闭环、配套国际 API、后台售后凭证查看、字段契约、自动化测试及对应实施记录。工作区中的京东 ERP 抽样导入日志与两个脚本不属于本轮发布，继续保留在本地且不暂存。
- 不写入生产密钥，不启用真实支付、短信、ERP、提现或对象存储，不更改维护、Worker 出站及业务开关。支付、退款和外部回执仍以生产实际配置状态为准。

## 本轮用户可见改进

- 补齐目录、搜索、详情、收藏、购物车、地址、服务端报价、下单恢复、订单、物流、评价、优惠券、积分、商品级售后及帮助入口，并保持国际账号与国内账号存储隔离。
- 结算页移除发票抬头；买家留言默认折叠，只有需要时展开。报价、库存、金额、优惠与幂等校验继续由服务端执行。
- 中国大陆地址由省、市、区三个自由输入框改为三级联动选择，保存行政区名称和代码；增加必填进度、逐项提示及浏览器自动填充提示。
- 商品详情增加分享入口：支持系统分享、微信右上角引导和复制规范商品链接，不携带会员、订单或员工推广身份。
- 售后支持剩余数量、现金与积分额度、重复提交恢复、退货物流及最多九张私有凭证；对象存储未配置时仍允许文字申请，不伪造上传成功。

## 发布与验收方式

- 发布前再次 fetch 并确认远端国际分支仍为本轮基线；仅显式暂存本轮文件，检查暂存差异与敏感信息后提交并推送 `codex/global-api-foundation`，不强推、不合并国内 `main`。
- 既有国际自动发布器只接受该分支的不可变提交，保留私有环境和维护状态，依次构建国际 API、Worker、Admin/H5，检查迁移、容器与公网版本；有待迁移或健康失败时必须停止/回滚，不能绕过门禁。
- 完成标准：公网 `/global/health` 的完整 revision 等于本次提交，数据库 ready；实际打开 H5 并核对商品分享、结算无发票且留言折叠、地址三级联动；同时确认国内 `/health/ready` revision 未变化。
