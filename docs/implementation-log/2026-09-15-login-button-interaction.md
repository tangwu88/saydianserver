# 2026-09-15 商城验证码与登录按钮交互修复

## 问题与范围

- 用户反馈本地商城登录页的“获取验证码”和“登录”按钮为灰色且无法点击，并要求重新发布国内及国际商城 H5。
- 现场检查确认国际生产 API 已恢复，`/global/health/ready` 为 `63fa77639a6a9babd889677e0e65ba02ccff1515`、数据库正常，国际能力接口已返回 `login.sms.enabled=true`。
- 当前本地 `127.0.0.1:5174/saidian-mall/` 是国内运行模式，代理的本地 API 返回 500；国内生产能力接口也将短信判定为未配置。旧前端把渠道能力直接绑定到按钮 `disabled`，导致用户不能点击并查看具体校验或配置提示。

## 修复

- 国内登录页的发码按钮只在请求中或倒计时期间禁用，登录按钮只在请求中禁用；渠道未启用时点击后显示后端能力原因或通用提示，不发起请求。
- 国际登录页的发码和登录按钮不再因能力、协议或初始化失败永久禁用；点击后仍按原顺序校验协议、手机号或邮箱、验证码挑战和渠道能力。
- 后端仍是唯一安全边界：渠道未配置、验证码未获取、验证码错误或协议未接受均不能建立会话；本轮不触发真实短信。
- 增加源码契约测试，防止后续再次把渠道可用性直接绑定成不可点击按钮。
